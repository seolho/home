택배 배송안내 알림톡 관리시스템 (다중 택배사)

[핵심]
- 기존 로젠택배 시스템과 delivery_shipments / delivery_send_logs 테이블을 함께 사용합니다.
- 템플릿 변수: [*이름*]=성명, [*1*]=상품명, [*2*]=택배사명, [*3*]=송장번호
- 배송조회(DS) 버튼은 승인 템플릿 버튼을 사용하며 PHP에서 URL/버튼을 보내지 않습니다.
- 엑셀/CSV 순서: 성명, 연락처, 상품명, 택배사명, 송장번호
- 개별 수동 등록/수정 시 택배사는 select로만 선택됩니다.

[지원 택배사]
우체국택배, 로젠택배, 일양로지스, FedEX, 한진택배, 경동택배, 합동택배,
롯데택배, 농협택배, 호남택배, 천일택배, 대신택배, 건영택배, CU편의점택배

[설치]
1. 폴더를 /delivery_manager_multi 로 업로드
2. config.php의 APP_BASE_URL 확인
3. config.php의 PPURIO_ACCOUNT / PPURIO_AUTH_KEY / PPURIO_SENDER_PROFILE 확인
4. 현재 다중택배 템플릿 코드는 ppur_2026091122290347407458088 로 입력되어 있음
5. make_hash.php에서 관리자 비밀번호 해시 생성 후 ADMIN_PASSWORD_HASH 교체
6. install.php 1회 실행 (기존 테이블이 있으면 그대로 재사용)
7. install.php 삭제 또는 이름 변경

[주의]
- 엑셀의 택배사명은 지원 목록과 정확히 일치하지 않으면 업로드에서 제외됩니다.
- 기존 로젠 시스템과 같은 테이블을 사용하므로 양쪽에서 데이터가 함께 보일 수 있습니다.
- 다중택배 템플릿 승인이 완료된 뒤 실제 발송 테스트를 진행하세요.
